Scarpe TUI / Scarpe AI — Final Review
Repo: TureCatedu/GSoc-2026 · Ruby DSL (Shoes-like) over a Rust/crossterm engine via C-ABI FFI, plus a multi-provider AI chat TUI. ~3.5k lines, single author. All findings below verified by building the crate and driving it under a pty unless noted.
🔴 Blockers
Plagiarism/attribution — ext/ffx.rb and ext/ffi.rb are byte-identical copies of tenderlove/ffx, presented in README.md:129-139 as project work. Upstream has no LICENSE (all rights reserved). It's also dead code — nothing invokes it. Fix: delete, or vendor with attribution + permission.
License — CC BY-NC-ND 4.0 (README.md:218) is not open source (NoDerivatives forbids forks/modification) and can't merge into Scarpe (MIT); GSoC requires OSI-approved. Fix: MIT.
Doesn't build on Linux — rust_core/cargo.toml is lowercase (cargo demands Cargo.toml; only works on case-insensitive macOS). After renaming it builds clean in 6s, zero warnings. ext/mylib.rb:6 hardcodes target/debug/librust_core.dylib — macOS-only, and debug while the README says build --release. Fix: git mv; select .so/.dylib by platform, prefer release.
Zero tests, zero CI — which is why everything below shipped. Fix: split App#new from App#run (the loop currently runs inside initialize, scarpe_tui.rb:129, making headless testing impossible), then GitHub Actions on Linux+macOS.
🟠 Verified bugs
Rust core / TUI
Orphan reader thread eats the first keystroke (context.rs:30-40) — the event thread is never joined; after free_context it stays blocked in read() and swallows one event. App runs Scarpe.app twice (setup→main), so first-run users lose their first keypress (reproduced 3/3: typed ABCDEF → got BCDEF). Fix: shutdown flag + event::poll timeout + join.
Two scroll systems fight — arrow keys (ffi.rs:324-351) and mouse wheel (ffi.rs:447,451) set the global scroll_offset_y=1, which is also the whole-UI draw offset (context.rs:509): the header row vanishes off-screen, and on the first wheel tick the chat doesn't even scroll (global and per-area offsets cancel). Reproduced both. Arrows also scroll every ScrollArea, ignoring focus. Fix: delete the global offset; keep only per-area offsets.
Mouse click discards queued input — return 2 at ffi.rs:464 drops the rest of the already-drained event batch. Reproduced: click+XYZ in one write → XYZ lost entirely. Fix: set a flag and finish the loop, as the Enter path does.
Checkbox is half-implemented — label silently dropped (ffi.rs:55 ignores text_ptr; renders bare [ ]) and callbacks never fire (toggle sets no clicked_btn, context.rs:490-497; poll returns 0, so Ruby's handle_click! never runs). Both verified; both documented as working in docs/api-reference.md:40.
Context lifetime race — the streaming thread can read @ctx_ptr and get preempted while the main thread frees it (scarpe_tui.rb:375-376); a call landing on the freed context silently returns STATUS_OK (verified — UB, not a crash). After @ctx_ptr = nil calls are safely rejected, so it's a narrow TOCTOU window, not sustained writes. Fix: alive-guard/generation counter; don't free while workers are outstanding.
AI app (examples/app.rb)
System prompt falls out of context — messages.last(20) (:264,269,275) is a tail slice; past 20 messages the system entry at index 0 drops and <write_file>/<execute_bash> silently stop working (Gemini branch re-attaches it, :283; the others don't). Fix: pin it outside the window.
Anthropic provider 400s — role:"system" inside messages[] is rejected on these models (system belongs in the top-level system param), and a tail slice starting on an assistant turn violates "first message must be user." (Consecutive same-role user turns are fine on the current API — the bash-observation pattern itself is OK.)
Streamed tokens lost at chunk boundaries — read_body { |chunk| chunk.split("\n") } (:296-299) with no carry buffer; an SSE line split across TCP chunks is swallowed by the bare rescue JSON::ParserError (:326). Demonstrated with their exact code: "Hello" dropped, " World" kept. Fix: buffer, process only complete lines.
Worker errors invisible — exceptions in the streaming thread print to stderr (report_on_exception), which is garbled/lost in the raw-mode alt screen; the response just stops. Fix: catch and render into the chat.
Smaller: duplicate attach_function (mylib.rb:18-19); free_string typed :uint64+.address (works on 64-bit, should be :pointer); header typo scape_tui_poll_events + stale exports (header/scarpe_tui_header.c:33); build_cli.rb:60 rescue Exception turns clean exit into "fatal error"; dead gsub (:31); /setup///clear exec away without restoring the terminal (app.rb:153-168).
🔒 Security (matters: the app gives an LLM file-write + shell-exec)
API key leaks to every AI-run command — ENV['API_KEY'] (:107) is inherited by Open3.capture3 (:410,445); any proposed env/curl/npm-postinstall exfiltrates it. Pass as a local.
Key stored group/world-readable — config written with default umask (:80); chmod 0600.
No write sandbox — <write_file path="..."> accepts /etc/…, ../.., ~/.ssh/… and mkdir-p's parents (:351,363). Confine to CWD, reject absolute/...
Consent is a persisted global off-switch — with it off, model output pipes straight to shell; combined with /read injecting arbitrary files, one poisoned README is prompt-injection→RCE. Make no-consent per-session.
Gemini key in the URL (:277) — logged by proxies; use the header.
🏗 Architecture
Threading: @node_stack is mutated by both the main loop and background threads (append_to in consent panels) — GVL interleaving can reparent nodes. Fix: workers post closures to a queue the main loop drains.
Per-frame cost: layout_node/draw_node_recursive/traverse_mouse each clone() every node's node_type (String) + children — two full-tree deep clones per streamed token. Use split borrows/indices.
No node removal — no delete FFI; the Slab and chat tree grow forever; long sessions degrade.
Editing is append-only — cursor keys unused for text (spent on scrolling), no mid-line edit/Home/End. Biggest functional gap for a Shoes edit_line.
Wrapping is char-count based — CJK/emoji misalign; use unicode-width.
DSL inconsistency — containers return raw int IDs, para returns TextNode, append_to takes an ID; align with Shoes slot objects early if Scarpe-compat is the goal.
🧹 Hygiene
17 MB .git for a 228 KB checkout (758 target/ files committed then deleted; DS_Store in 4 commits). .gitignore uses trailing comments, which git doesn't support — /target/ #…, .idea/ #…, .vscode/ #… are inert (verified with check-ignore); *.json ignores every JSON in-tree. Commits titled . (×3). ffi pinned to 2021's 1.15.5; crossterm 0.27 vs current 0.29.
✅ Genuinely good
Every FFI entry point is null-checked and catch_unwind-wrapped with typed status codes mapped to Ruby exceptions — the right instinct at an unwind boundary. The diff renderer with color/attr run-tracking and clip-rect scroll clipping is clean and correct. Slab DOM, Copy styles, double-buffer+swap: sensible. Compiles warning-free (6 cosmetic clippy lints). Docs are unusually thorough and mostly accurate. The DSL genuinely reads like Shoes.
